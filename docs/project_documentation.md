# AI Powered Sign Language Learning & Assessment Platform

## Project Overview

The AI Powered Sign Language Learning & Assessment Platform is a web-based application designed to help learners acquire sign language skills through structured lessons, AI-based gesture recognition, real-time feedback, and interactive assessments.

The platform combines Artificial Intelligence, Computer Vision, Machine Learning, and modern web technologies to create an accessible and engaging learning environment.

This project is being developed as part of the Infosys Springboard Virtual Internship Program.


# Problem Statement

Millions of people rely on sign language for communication, yet access to structured learning resources remains limited. Traditional learning methods provide minimal personalized feedback and often require instructor supervision.

The proposed platform addresses these challenges by enabling learners to practice sign language independently while receiving AI-driven gesture evaluation and performance feedback.


# Project Objectives

• Build an interactive sign language learning platform.

• Enable AI-based sign recognition using computer vision.

• Provide real-time gesture feedback.

• Track learner progress through assessments.

• Improve accessibility using intelligent technologies.

# Datasets Used

## ASL Alphabet Dataset

Purpose:

Used for training the AI model to recognize static American Sign Language alphabet gestures.

Contains:

- 29 classes
- RGB images
- Training and testing folders


## Sign Language MNIST Dataset

Purpose:

Used for benchmarking gesture classification models.

Contains

- sign_mnist_train.csv
- sign_mnist_test.csv

Features

- 28×28 grayscale images
- Pixel values
- Label column
